# LuxeInfra — service-led UI redesign, version 13

21 October 2026. Local review build. No live publishing or DNS changes.

## What changed

This pass replaces the earlier editorial homepage layout with a more direct interior-design browsing experience, using the current public Livspace and HomeLane site structures as references. No competitor copy, photography, ratings, warranties or numerical claims were imported.

- Stronger Manrope typography, clearer headings, rounded image cards and a consistent blue/ivory visual system across the existing pages.
- Two-level desktop navigation: primary services/tools and directly accessible room collections. Quote and calculator actions are distinct.
- A main room image with manual scene choices and a companion project selector. Whole-home, kitchen and wardrobe selections carry into quote/budget links.
- Visual room shortcuts and larger cards for complete homes, kitchens and storage.
- A filterable inspiration gallery with working save controls, three/six-image expansion and links to the relevant design in its room collection.
- Separate home/kitchen/wardrobe budget entry cards; wardrobe-specific entries do not preselect kitchen work. The summary image follows a wardrobe-only selection.
- 2/3/4+ BHK planning cards preselect the right configuration.
- Stronger benefits, style discovery, room studio, materials, process, region and FAQ sections.
- Mobile quote/budget actions on browsing pages; these stay off estimate, callback, detailed-brief and room-studio workspaces to avoid distracting from an active task.
- The short callback keeps its four required fields and customer-sent WhatsApp/email handoff. No automatic delivery confirmation was added.

## Validation and limits

- Final type checking and production build passed. All 22 existing automated checks passed. Fifteen route checks and 33 homepage asset checks also passed; contextual links are present, the missing-page response is correct, and public AI remains disabled.
- The refreshed homepage was checked visually in a separate task-only Chrome window. Wardrobe selection and its budget link were verified to preserve the wardrobe scope. This also identified the summary-image fix.
- Automated approval blocked access to an unrelated private Chrome window. A separate preview window was used instead; unrelated browser content was not read.
- Further native browser actions were stopped when user interaction was detected. A full mobile interaction review of version 13 is still outstanding; responsive rules are implemented but are not claimed to be browser-certified.
- Rates, authentic reviews/projects, product specifications, media rights, commercial terms and deployment prerequisites remain as documented in owner-inputs/START-HERE.md. Public AI remains disabled.
